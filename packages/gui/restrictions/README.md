# 禁卡表（卡牌的使用限制）

每个文件是一张禁卡表，GUI 启动时读取这个文件夹里的全部 `*.json`（`src/formats/lists.ts`），在组卡界面和开局页的"禁卡表"里按赛制列出。

命名：`<最后更新的月>_<年的后两位>_<地区>[_CROSS].json`（地区：`JPN` 亚洲、`EN` 欧美、`CHN` 中国大陆），例如 `10_26_JPN.json`、`08_26_CHN.json`、`11_26_EN_CROSS.json`。文件名就是禁卡表的名字。官方更新时，新建一个文件（旧的可以留着），不用改代码。官方提前公布、以后才生效的表也可以先加上，旧的留到新表生效以后。

```json
{
  "format": "standard",
  "region": "asia",
  "updated": "2026-01-30",
  "source": "https://shadowverse-evolve.com/card_limit/",
  "banned": [{ "card": "BP13-107", "name": "ワールドブレイク", "since": "2026-01-30" }],
  "limited": [{ "card": "BP02-062", "name": "竜巫女の儀式", "since": "2026-01-30" }]
}
```

| 字段 | 含义 |
|---|---|
| `format` | 适用的赛制：`standard`（标准）或 `crossCraft`（双职业） |
| `region` | 地区：`asia`（亚洲，日文官网）、`en`（欧美，英文官网）或 `china`（中国大陆） |
| `updated` | 官方最后一次更新的生效日期（不早于每张卡的 `since`） |
| `source` | （可选）官方页面 |
| `banned` | 禁止卡：卡组里一张都不能放 |
| `limited` | 殿堂入り / Restricted to 1：卡组里最多放 1 张 |
| `minimumPerLeaderClass` | （双职业，可选）主卡组里每个主战者职业至少要有的张数。综合规则 B-2 是 1 张；欧美官网的双职业规则是 9 张，写在欧美的双职业禁卡表里 |

- `card` 是卡牌编号（任何一个印刷版本都可以），按这张卡计算张数：它的所有印刷版本（异画、再版）合在一起算，主卡组和进化卡组都算。卡名相同的进化卡是另一张卡，不受影响（例如『天下の大泥棒・ジエモン』的进化卡可以放 3 张）。
- `name` 是官方页面上的写法，只用来核对：测试会检查它和这个编号的日文（亚洲）、中文（中国大陆）或英文（欧美）卡名一致。
- `note`（可选）写特殊情况，例如官网的链接写错了编号，或者官方的写法和卡牌数据不同。
